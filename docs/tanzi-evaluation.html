2这个 Skill 是啥

tanzi 是一个用来采集和整理多平台公开信息的 skill，主要依赖 AI agent、OpenCLI、浏览器登录态和公开接口，通过关键词拆分、渠道选择、正文读取、筛选与记录完成采集任务，主要服务需要资料可追溯的研究、内容和咨询人员。

1使用方法

  • 围绕明确话题采集多个平台
  • 为研究或写作准备候选材料
  • 核对来源、正文状态和互动数据

2任务步骤

  1. 确认主题、时间和平台范围
  2. 拆分关键词并选择必要渠道
  3. 获取候选材料和正文
  4. 筛选结果并记录失败情况
  5. 交付报告、清单和复核材料

3额外需要

  • 需要能够读取 Skill 的 AI agent
  • 中文平台通常需要 OpenCLI
  • 部分平台需要账号登录态
  • 代码或视频可能需要额外工具

4最后交付

  • 可以得到采集报告和候选清单
  • 可以得到正文或必要摘录
  • 可以保留原始响应供复核

3这个 Skill 好用吗

好用度：6.6/10

完整度较好，工作流、渠道、交付和安全规则齐全。优势和不足相比，可追溯和只读设计的权重更大。

好用之处

  • 渠道按研究问题选择，不会默认把所有平台跑一遍。
  • 原始链接、时间、正文状态、失败和降级都有记录。
  • 社区样本和事实材料分开，避免把讨论热度当总体数据。
  • 只执行平台读取，不发帖、评论、点赞或导出 Cookie。

可能卡住

  • 中文内容平台和 X 通常需要浏览器扩展及登录态。
  • 平台接口经常变化，工具存在也不代表当天一定能取到内容。
  • 公开项目刚发布，长期维护和跨设备表现还没有足够记录。

安装准备

前期准备是否必须用户影响
额外软件安装
  • 安装Skill｜必须｜需要支持 Agent Skills 的 AI agent
  • 中文平台｜按条件｜通常需要 Node.js、OpenCLI 和扩展
  • 代码视频｜按条件｜可能需要 GitHub CLI 或 yt-dlp
平台越多，需要安装和维护的工具越多；首次调用会先检查并说明。
额外注册/登录的账号
  • 公开接口｜不需要｜可直接读取允许匿名访问的来源
  • 内容平台｜按条件｜X、小红书等可能需要浏览器登录
登录不足时会跳过对应渠道，并在报告中写明覆盖缺口。
API KEY/联网服务
  • 基础采集｜不需要｜公开版不调用按次付费接口
  • 可选来源｜按条件｜少数学术或搜索服务可配置 Key
使用可选服务前需要核对额度、数据政策和当前规则。
涉及的数据与隐私
  • 查询内容｜必然涉及｜关键词和网址会发送给相应平台
  • 登录来源｜按条件｜读取当前浏览器已有登录态
  • 采集结果｜必然涉及｜报告和原始响应保存在本地
应使用有权访问的账号，避免在查询词和本地文件中放入敏感信息。

4这个 Skill 适合你吗

适合度：8.0/10

tanzi 部分适合需要围绕明确主题采集多平台公开信息并核对来源的研究、内容和咨询人员安装。

适合场景

  • 行业研究、内容选题和竞品观察
  • 需要同时查看中文与海外讨论
  • 希望保留来源、正文状态和失败记录
  • 愿意按平台准备工具与登录态

不适合场景

  • 只查一个事实或读取一个网址
  • 希望直接生成可发布文章
  • 要求所有平台长期稳定匿名访问
  • 需要自动发帖、评论或账号运营

5使用节奏建议

  1. 第一次用一个小主题和两三个平台试采，检查链接、正文状态和失败记录。
  2. 确认结果符合需求后，再增加平台、时间范围和候选数量。
  3. 平台报错时先做小结果上限测试，连续失败就停止该渠道并保留错误。
  4. 依赖长期不用或登录维护成本超过收益时，移除对应工具或停用。
